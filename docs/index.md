# Tidy

Tidy is a command-line tool that sorts the files in a messy folder into subfolders by type. Run one command, and your Downloads folder goes from chaos to order.

!!! note "This is a portfolio project"
    Tidy is fictional. This site shows how documentation can be written, checked, and published like software.
